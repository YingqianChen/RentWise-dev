# 第三批：请求边界、账户限额和无外部调用的页面读取

## Review 后已修复

- 登录 JSON/UTF-8/字段校验错误统一返回 422，不回显密码或校验器内部对象。JWT 必须包含有效的用户 UUID 和到期时间。注册时并发撞邮箱返回可解释冲突。
- 项目与候选的非空字段显式拒绝 null/空白；预算、邮箱、密码、地点和备注限制在存储可接受的范围。可清空的可选值仍能清空。
- 整个 HTTP 请求在解析前限制大小：普通请求 256 KiB，图片导入 32 MiB。流式内容也逐块计数，不能靠缺失或伪造 Content-Length 绕过。原有 8 张/单张 10 MiB/总图片 30 MiB 限制仍生效。
- PostgreSQL 原子计数提供跨进程固定时间窗口限额：每来源注册 30/小时、登录 20/分钟；每邮箱登录 30/小时；每账户 AI 操作 5/分钟、50/UTC 日。限额可配置；拒绝返回 429 与 Retry-After。数据库不可用时返回 503，不放行额外调用。
- 限额事务独立于业务事务：失败登录/失败分析不会通过回滚退还次数。记录仅保存 HMAC 身份摘要，过期窗口在后续请求时清除。
- 分析额度涵盖导入、重新分析、改变来源后的分析、主动生成沟通草稿。免费检查中断、确认事实、本地计算和未改变原文的重命名不占额度。
- 候选和比较页只读取相符的通勤缓存；不自动调用地图或通勤代理。比较摘要改由确定性分组本地生成，不因页面加载额外请求模型或提升结论置信度。
- 并发仪表盘/调查刷新在数据库事务内串行同步任务，避免首次读取时重复插入同一任务；保存的状态和笔记保持不变。项目删除及候选删除与这些操作互斥。
- 金额解析拒绝范围、负数、外币和畸形数字；支持明确的 k/万元及半个月、1½ 月等租金倍数。避免截取第一个数字直接计算。

本地普通后端 322 passed，23 skipped，1 deselected，另 25 subtests；独立 PostgreSQL 21 passed。新增覆盖流式请求、密码不回显、坏 token、无效 patch、12 个并发申请仅批准 3 个、失败登录计数不回滚、额度用完仍可重命名和检查中断、8 个并发仪表盘读取、页面不调用模型或通勤计算。没有真实模型请求。
